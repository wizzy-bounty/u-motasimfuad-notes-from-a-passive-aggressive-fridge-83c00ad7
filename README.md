Entry for the make.fun competition "Notes From a Passive-Aggressive Fridge".

`main.py` writes one passive-aggressive note from a smart fridge to its
owner into `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`,
defaulting to `/output`). Python standard library only, deterministic,
no network access.
